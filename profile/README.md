## Возможности финальной версии

1. Прием заявок и удобное модерирование для рекрутов
2. Система AFK и отпусков
3. Система мероприятий (MCL, VZZ, Warzone, Capture)
4. Веб-сайт для удобной и гибкой настройки бота + система конфигов настроек и статистики
5. Система оповещений о начале трансляций на Twitch или выходе видео на YouTube
6. Удобная система отчетов с мероприятий
7. Система архивов для всех игроков + тир-система
8. Магазин за баллы сервера, за которые можно покупать различные товары

> ⚠️ Важно учитывать, что функционал будет дополняться со временем.
